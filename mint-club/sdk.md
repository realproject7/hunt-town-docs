# SDK & Integration

Everything the no-code Mint Club interface does — create assets, mint, burn, run airdrops and
lock-ups — is also available programmatically through the **Mint Club V2 SDK**. The SDK is how
developers and partner teams build their own products on top of Mint Club's curves.

## What the SDK enables

- **Create** ERC-20 tokens and ERC-1155 NFTs on bonding curves from code.
- **Mint and burn** against any Mint Club curve programmatically.
- **Read** curve state — prices, supply, reserve — to power custom UIs and trading logic.
- **Manage** assets — airdrops, lock-ups, and other creator operations.

## Why it matters

The SDK is the reason Mint Club functions as a **protocol, not just an app**. Multiple
external products in the [Build Log](../track-record/build-log.md) were built by independent
teams against Mint Club's contracts and tooling:

- **Farcards** and **Memberify** — ERC-1155 collectibles/memberships on Mint Club curves.
- **Hamcaster** — a full third-party SocialFi token economy on Mint Club contracts.
- **MCDegen**, **PumpSea**, **Hyped.club**, **MintDrop** — consumer trading and reward
  products built on the curve engine.

Each of these used the same primitives the SDK exposes, which is the strongest evidence that
Mint Club is a reusable building block for the wider Builder & Agent Economy.
