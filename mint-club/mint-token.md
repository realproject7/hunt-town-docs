# MT (Mint Token)

**MT (Mint Token)** is Mint Club's platform token. It is itself a **HUNT-backed child
token**.

| | |
| --- | --- |
| **Network** | Base |
| **Contract** | `0xFf45161474C39cB00699070Dd49582e417b57a7E` |
| **Reserve** | HUNT on Base, held by the Mint Club V2 Bond |

> **History.** Mint Club previously used a token called **MINT**. The **MINT → MT migration
> concluded on June 5, 2025**, after which **MT powers Mint Club exclusively**. References to
> "MINT" in older material refer to the pre-migration token.

## What MT does

- **Buyback & burn.** Mint Club's own token model: platform fees buy back MT and burn it.
  Buybacks run periodically, based on market conditions.
- **Parent token.** MT is itself a reserve asset on Mint Club: creators can launch
  MT-backed child tokens and NFTs.
